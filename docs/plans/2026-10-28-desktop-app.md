# Desktop app: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An unsigned macOS Tauri v2 app that starts the user's installed Trillion server with a token it made, shows a splash orb until it answers, lives in the menu bar, hides on close, opens sign-ins in the browser, and makes the talk shortcut work from any app with a floating orb.

**Spec:** `docs/specs/2026-10-28-desktop-app.md` (read it whole first).

**Tech stack:** Rust (Tauri 2.x, `tauri-plugin-global-shortcut`, `tauri-plugin-opener`, `tauri-plugin-autostart`, `tauri-plugin-window-state`), Python 3.13 (uv, pytest, ruff, strict mypy), TypeScript (Vite, vitest, jsdom).

**Branch:** `desktop/app` (holds the spec).

**House rules:** `git commit -s`, message ending in a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; only `git add` your files; generic names only (`scripts/containment_check.py`); short plain comments that say why; never play sound; never print or commit `src/trillion/connectors/google/google_client.json`. Checks: `uv run pytest -q`, `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy`, `python3 scripts/check_one_writer.py`, `python3 scripts/containment_check.py`, `python3 scripts/check_raw_hex.py`, `python3 scripts/check_agent_name.py`; web `pnpm -C apps/web test && pnpm -C apps/web typecheck && pnpm -C apps/web build`; desktop `cargo test`, `cargo clippy --all-targets -- -D warnings`, `cargo fmt --check` in `apps/desktop/src-tauri`.

**Dev note:** the user runs Trillion from this repo, not an installed tool. `apps/desktop/scripts/trillion-dev` (executable sh) runs `exec uv run --project "<repo root, resolved from the script's own path>" trillion "$@"`, and the desktop `dev` script sets `TRILLION_BIN` to it.
