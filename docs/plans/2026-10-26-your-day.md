# Your day: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** "What's my day?" or the "Your day" entry opens today's day conversation, where she builds a live board from what's connected and says what matters in two sentences.

**Spec:** `docs/specs/2026-10-26-your-day.md` (read it, and `docs/design/widgets.md`).

**Architecture:** A day conversation is a conversation with `kind = "day"` and a date. `persona/day.py` composes the recipe; the session takes `day.build` like it takes `greet` (host-authored input); the `day_open` tool asks the page to open the day. The page shows a "Your day" row and switches to it.

**Tech stack:** Python 3.13 (uv, pytest, ruff, strict mypy); TypeScript (Vite, vitest, jsdom).

**Branch:** `day/your-day`.

**House rules:** `git commit -s`, message ending in a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; only `git add` your files; generic names only (`scripts/containment_check.py`); short plain comments that say why; never play sound; no browser. Checks: `uv run pytest -q`, `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy`, `python3 scripts/check_one_writer.py`, `python3 scripts/containment_check.py`, `python3 scripts/check_raw_hex.py`, `python3 scripts/check_agent_name.py`, `uv run python scripts/gen_kit_samples.py --check`; web `pnpm -C apps/web test && pnpm -C apps/web typecheck && pnpm -C apps/web build`. Keep the workspace tool budgets.
