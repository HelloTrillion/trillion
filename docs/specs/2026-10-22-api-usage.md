# The "API usage" pill

**Date:** 2026-10-22 · **Requirements:** BRN-4 · **Leads into:** BRN-7, BRN-8

Every model call (each round of a turn, a compaction, a title, a draft, background work) writes one row to `usage` (provider, model, four token counts, `cost_usd`); since the spend caps, the metered providers write it (see [spend caps](2026-11-04-spend-caps.md)). Nothing reads it back. This slice reads it back: one endpoint, a pill in the header, and a breakdown in Settings. It records nothing new and changes no schema.

## What "this month" means

From midnight on the 1st, in the user's timezone (`USER.md`, set in Names and tone). If none is set, the machine's local time. Its tooltip and accessible name say which month it counts.

## Unknown cost stays unknown

When this slice was built only Anthropic models had prices; an OpenAI-compatible provider recorded `cost_usd` as NULL ([spend caps](2026-11-04-spend-caps.md) added prices for more). A NULL is never counted as $0. The total is the sum of priced rows, and the tokens from unpriced rows are shown beside it as unpriced, so a bill cannot look smaller than it is.

## Store

`ConversationStore.usage_since(owner_id, since_ms)` groups rows by provider and model and returns, per group: the four token sums, `SUM(cost_usd)` over priced rows (NULL if none), and the number of unpriced rows (one per model call, reported as `unpriced_turns` for compatibility) and their tokens (all four kinds; each provider reports them as separate, non-overlapping counts). Read only.

## API

`GET /api/usage`, behind the same session token and origin check as every API request (SPN-11).

```json
{
  "month": "2026-10",
  "since_ms": 1790812800000,
  "rows": [
    {"provider": "anthropic", "model": "claude-…", "input_tokens": 41000, "output_tokens": 9000,
     "cache_read_tokens": 2000, "cache_write_tokens": 0, "cost_usd": 1.2,
     "unpriced_turns": 0, "unpriced_tokens": 0},
    {"provider": "deepseek", "model": "deepseek-chat", "input_tokens": 300000, "output_tokens": 40000,
     "cache_read_tokens": 0, "cache_write_tokens": 0, "cost_usd": null,
     "unpriced_turns": 57, "unpriced_tokens": 340000}
  ],
  "total_cost_usd": 1.2,
  "unpriced_tokens": 340000
}
```

`total_cost_usd` is null when no row is priced. Rows are ordered by cost, then tokens, largest first.

## The pill

A small rounded badge in the header, top right, beside "New conversation". It is the first pill in the page, so it gets its own class (`.usage-pill`) for BRN-8 to colour later.

| Month so far | Pill |
|---|---|
| Nothing used | `No API use yet` |
| All priced | `$1.20` |
| Some priced | `$1.20 · 340k unpriced` |
| None priced | `340k tokens` |

The full sentence ("API usage in October: $1.20, plus 340k tokens from models without prices") is its accessible name and tooltip. The page fetches `/api/usage` on load and again after each `turn.complete`. If the fetch fails, the pill hides; it never shows a stale or guessed number. Clicking it opens Settings at Usage.

## Settings → Usage

A read-only section in the **You** group: one line per provider and model with cost (or "no price") and tokens in and out, then the month's total. Built with the existing `panel.add` section, like the others.

## Tests

- `tests/api/test_usage.py`: rows are grouped by provider and model; a row just before the 1st (in the user's timezone) is left out and one just after is counted; NULL cost is never summed as zero; a mixed month gives the right total and unpriced tokens; no token → 401, foreign origin → 403.
- `apps/web/test/usage.test.ts`: the pill text for each case in the table above, and the accessible sentence.

## Not covered

- **Voice providers.** ElevenLabs and Deepgram recorded no usage here. They do now, in characters and minutes: see [spend caps](2026-11-04-spend-caps.md).
- **Per agent.** BRN-4 says per agent; there is one agent today, so there is nothing to split. The table can take an `agent` column when there is a second.
- **Prices for OpenAI-compatible models.** Left for BRN-7, which needs prices to enforce a cap. Built: a price table for common OpenAI and DeepSeek models, OpenRouter's own cost, and your own price per model in Settings (see [spend caps](2026-11-04-spend-caps.md)).
- **Caps and the warning state** are BRN-7 and BRN-8, built in [spend caps](2026-11-04-spend-caps.md). The pill only gained state classes.

## Possible follow-up: a status line

The pill could later sit in a footer "status line": one quiet strip under the input that holds short live readouts (usage, shared folders, model, listening) in one place, the way an editor's status bar does. Proposed here, not built; it is a layout change worth its own issue.
